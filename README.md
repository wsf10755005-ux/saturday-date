# 週六的小約會 ♡

使用原生 HTML / CSS / JavaScript，無須安裝套件。Google 字型載入失敗時會使用系統字型。

## 資料庫連線

請依照 [連線設定](連線設定.md) 部署 [Code.gs](Code.gs)，將部署網址填入 [config.js](config.js) 的 endpoint。未設定時，頁面會顯示資料庫尚未接通，不會顯示假成功。

## 發布到 GitHub Pages

1. 在 GitHub 建立一個儲存庫。
2. 將 index.html、style.css、config.js、script.js 上傳到儲存庫根目錄。
3. 開啟 Settings → Pages，選擇 Deploy from a branch。
4. 選擇 main 分支與 / (root)，按 Save。
5. 等待 GitHub 提供網站網址，把網址傳給另一半。

## 功能與資料

- 自動以訪客裝置日期顯示最近的週六，週六當天會顯示當天。
- 晚餐轉盤：日料、烤肉、速食，可重轉。
- 所有問題必須回答，晚餐必須轉出結果後才能送出。
- 是與否都能自由選擇；親密心情提供 0–4 選項，任何時候都能改變心意。
- 同意抱抱睡時顯示「你成功預約」；選擇否時顯示「你的心意已收到」。
- 勾選同意後，送出最終選擇，以及兩題的「否」總點擊次數與首次點「是」前的次數。頁面會即時顯示次數，未送出不傳送。次數只計算本次開啟頁面，不跨裝置追蹤。
- 收到後端寫入確認後才顯示成功，可複製結果。網路失敗保留答案，相同內容重試不重複新增。重新整理會清除選擇與計數。
- 剪貼簿功能在 HTTPS 網站通常可用；本機檔案模式若無法複製，可手動選取結果。
